# PBA Website - Program Studi Pendidikan Bahasa Arab

Website modern, responsif, dan profesional untuk Program Studi Pendidikan Bahasa Arab (PBA). Dibangun menggunakan React.js, Tailwind CSS v3, Framer Motion, dan Lucide Icons.

## Fitur Utama
- **Data Dosen**: Menampilkan profil pengajar dengan filter pencarian.
- **Data Mahasiswa**: Visualisasi statistik dan direktori mahasiswa.
- **Informasi Akademik**: Kurikulum, visi misi, dan berita terkini.
- **Desain Modern**: Animasi halus dengan Framer Motion dan UI bersih dengan Tailwind CSS.

## Teknologi yang Digunakan
- **Frontend**: React.js (JSX)
- **Styling**: Tailwind CSS v3
- **Animasi**: Framer Motion
- **Ikon**: Lucide React
- **Build Tool**: Vite

## Struktur Proyek
```text
src/
├── components/     # Komponen reusable (Navbar, Footer, Card, dll)
├── pages/          # Halaman utama (Home, Dosen, Mahasiswa, dll)
├── data/           # Mock data / JSON data
├── styles/         # Global styles dan utilitas CSS
└── assets/         # Gambar dan media
```

## Cara Menjalankan
1. Clone repositori ini.
2. Jalankan `npm install` untuk menginstal dependensi.
3. Jalankan `npm run dev` untuk memulai server pengembangan.
4. Buka `http://localhost:5173` di browser Anda.

## Pengembangan
- Gunakan komponen reusable untuk konsistensi.
- Pastikan setiap halaman responsif (mobile-first approach).
- Tambahkan animasi micro-interaction untuk meningkatkan UX.
